# Pruebas y validación

Esta sección se utilizará para documentar únicamente pruebas realizadas sobre el prototipo.

## Criterios

- Comunicación ESP-NOW entre transmisor y receptores.
- Lectura y validación RFID.
- Comportamiento del filtrado RSSI.
- Confirmación de estados.
- Activación y restablecimiento de alarmas.
- Comunicación con Arduino IoT Cloud.
- Autonomía y comportamiento de alimentación, cuando existan mediciones.

## Evidencia

Las fotografías, videos, tablas y valores medidos se incorporarán conforme se disponga de evidencia del proyecto.

> No se incluyen métricas estimadas o resultados no medidos.
